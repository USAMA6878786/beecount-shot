# 记账截图 for 蜜蜂记账

**点一下控制中心，把当前屏幕记成一笔账。**

蜜蜂记账有个自动记账功能：只要检测到系统截图就去识别记账。
随手截个图也会变成一笔脏账。

这个模块把主动权交回给你——**只有你点「记账截图」磁贴那一下，它才记账。**

---

## 它能做什么

- **想记才记**　平时的截图（电源键、三指、长截屏）不再产生脏账
- **一下就好**　下拉控制中心点磁贴，面板自动收起、自动截图、自动交给蜜蜂记账
- **有回音**　截完屏幕立刻提示「截图成功」，不用去相册确认
- **相册不乱**　识别完成后自动把这张截图删掉，不想要可以在设置里关掉
- **桌面看账**　桌面小组件显示今日 / 本周 / 本月支出，白底、透明度可调
- **也能更快**　可选的截图加速，比默认方式快约三分之一（首次可做一次校准）
- **后台不丢**　蜜蜂记账被清出后台后，模块会自动把它叫回来，小组件照常显示实时数字

---

## 要求

Android 8.0 以上，已装 LSPosed，手机有 root。

---

## 安装

1. 下载并安装 APK
2. 打开 **LSPosed** → 启用「记账截图」→ 作用域勾选「蜜蜂记账」
3. 打开一次**蜜蜂记账**，允许它的 root 请求
4. 进蜜蜂记账的「智能记账」，确认**截图监听是开着的**
5. 打开「记账截图」：点一次「root 权限」，再点「添加」把磁贴放进控制中心

> 更新模块后，请点一次设置页的「重启蜜蜂记账」，新功能才会生效。

---

## 使用

**记一笔**
下拉控制中心 → 点「记账截图」→ 完事。连点几次也可以，每张都会单独记账。

**加小组件**
长按桌面空白处 → 添加小部件 →「记账支出」。

**调透明度**
设置页的滑块会应用到所有小组件；只想改某一个，就长按那个小部件重新配置。

---

## 常见问题

**点了磁贴没反应？**
看设置页顶部的状态点，它会告诉你缺什么：没 root 就授权，没连上蜜蜂记账就点「重启」。

**改了设置没生效？**
点「重启蜜蜂记账」即可。

**截图里带着控制中心？**
说明这台手机收面板比预想的慢，把设置里的等待时间调大一点。

## 权限说明

| 权限 | 用来做什么 |
|---|---|
| root | 截图、收起控制中心、删除截图、重启蜜蜂记账 |
| 无障碍 | 备用截图方式，仅在 root 截图失败时使用 |
| 读取照片 | 判断截图是否已保存，加快确认速度 |
| 悬浮窗 | 让「截图成功」的提示在后台也能显示 |
